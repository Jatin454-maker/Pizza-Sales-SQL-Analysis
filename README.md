# Pizza Sales SQL Analysis 🍕

This project contains SQL queries for analyzing a Pizza Sales Database.  
It covers database creation, table relationships, basic queries, advanced SQL concepts, CTEs, window functions, and business insights generation.

## 📌 Project Overview

The project is designed to practice and demonstrate:

- SQL table creation
- Primary & Foreign Key relationships
- Data analysis using SQL
- Aggregate functions
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Revenue analysis
- Sales insights generation

The database simulates a pizza store management system where orders, pizzas, pizza types, and sales details are analyzed.

---

## 🗂 Database Structure

The project contains 4 tables:

### 1. `orders`
Stores order date and time information.

### 2. `order_details`
Stores quantity and pizza details for each order.

### 3. `pizzas`
Stores pizza sizes and prices.

### 4. `pizza_types`
Stores pizza categories and ingredients.
